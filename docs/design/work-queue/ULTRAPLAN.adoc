= Work queue: plan after the MVP
:toc: macro

Status: agreed with the owner on 2026-11-25. The MVP tiers 0 to 3 are on
main (PRs #1 to #7). This plan covers what comes next, in order. Each phase
names the evidence that closes it; nothing is done until that evidence is
recorded.

toc::[]

== Facts this plan starts from (2026-11-25)

* None of the work-queue checks run in CI. TLC, conformance, mutants and the
  `q` golden tests run only when someone runs them by hand.
* The CI gate fails on main because `actions.lock` lists
  `.github/workflows/ci-gate.yml` and `ci-gate-tamper-guard-caller.yml` with
  no `uses:` entries, while #5 pinned both to
  `hyperpolymath/proven-cicd-and-workflows@6a35e51`.
* `scripts/lock-sync-fix.sh` cannot repair it: it reads the trailing pin
  comment `# cicd-suite ci-gate` as a tag name, and no such tag exists. This
  is template code, so the bug is in `rsr-template-repo`.
* `estate-rules` fails in `tests/workflows/adopt_canon_lockstep_test.sh`
  (untraced). The template is not instantiated, which keeps Canon lockstep,
  openssf-compliance, the Central Estate audit and mint-gates red, and there
  is no root `.pre-commit-config.yaml` for pre-commit.ci.
* Proof scope: TLC checks finite models (three or four jobs). Conformance is
  exhaustive only for those models.

== Order and handoff

A, B and C run in one Sonnet session, as separate PRs in that order. D and E
start once A is merged, so every later PR is checked in CI. E is proof work
and gets a top-tier session of its own.
