= Findings and decisions

== Findings

*A job rejected for ever starves everything below it.* Liveness fails for the
contract as drafted. j1 is rejected at checkpoint, returns to `ready`, is
re-admitted, and is rejected again for ever. Because j1 is the most urgent
ready job, j3 is never admitted. With the reject limit, j1 is held
(`reject limit`) after two rejects and needs an owner edit, and both
NoStarvation and Terminates hold. `scripts/wq-oracle.sh` fails if this
counterexample ever disappears.

*Why the first TLC runs never finished.* The reject counter grew without
bound. It now stops at the limit; nothing reads it above that value, so no
behaviour is lost.

*A model can hide a rule from the mutants.* Tier 1's first shares model gave
every job its own obligation, so the "share rival ignores obligation" mutant
survived. Model 2 was changed so each conjunct of the share rule decides in
some reachable state.

*Correction to #1.* #1 reported 15 of 15 mutants caught. One did not compile,
and the script counted that as a catch, so the priority rule was not
mutation-tested. Fixed in #2: a mutant counts only if it compiles and then
fails conformance.
