= Work queue: design and status
:toc: macro

A small BOINC-style work queue for one owner's estate of repositories and
agent sessions: a few workers, category shares, an admission gate, hard
resource limits, priorities, single ownership of each obligation, and
recovery through leases and checkpoints.

This folder is the map. Each topic has one home; the pages below link to it
rather than copy it.

== Status (2026-11-23)

* *On main:* the spec and both models, the pure Zig core checked against every
  TLC state and transition (three oracles), category shares, the event-log
  store, the `q` CLI with `q board --json`, and `q run`. PRs #1 to #5.
* *Open:* #6, the live board (`q board --html`), a draft.
* *Not yet run:* the real memory-limit acceptance test for `q run` (needs a
  Linux host with a systemd user session).

== Rebuild and check

----
just wq-conformance   # TLC model check, all oracles, conformance
just wq-cli           # the q CLI golden scenario on a scratch $WQ_HOME
just wq-mutants       # mutation check (about 12 minutes)
----

The design notes were first drafted for the GitHub wiki; they live here
instead so they are versioned and reviewed with the code.
